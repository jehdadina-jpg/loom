# Market Street Phaser Demo

## Run it tonight

1. Keep `index.html` and the `public` folder together in this project.
2. Double-click `index.html`.
3. Allow internet access if your browser asks: Phaser and Chart.js are loaded from CDN script tags.

The market street appears with an animated shopkeeper patrolling near the stall.

## Optional local preview

If Node.js is installed, from this folder run:

```powershell
npm run dev
```

Then open the local address printed in the terminal (usually `http://127.0.0.1:5173`).

## Files used

- `index.html` — the complete game page, CSS, and JavaScript.
- `public/background-extended.png` — widened street background used by the game.
- `public/background.png` — original street background reference.
- `public/stall.png` — 1368×768 fruit-stall background used by the mini-task.
- `public/stall-overscan.png` — expanded fruit-stall scenery used to fill the viewport.
- `public/player-spritesheet.png` — copy of the player sheet used by the game.
- `public/spritesheet.png` — original player sprite sheet.

No build step or npm packages are required for the double-click launch.
